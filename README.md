# 🧪 Chemistry Game

## Introduction

An interactive chemistry learning platform through gamification, helping students learn chemistry in a fun and effective way.

**Course Project**: CT313 - Web Application Development  
**University**: Can Tho University - College of ICT

---

## Features

- 🎮 Multiple game modes: practice, challenge, competitive
- 👤 User account and profile management
- 🏆 Scoring system, leaderboards, and achievements
- 📊 Personal learning progress tracking
- 📱 Responsive and user-friendly interface
- 💾 Automatic progress saving

---

## Tech Stack

### Backend

- Node.js + Express.js
- MySQL + Sequelize ORM
- JWT Authentication

### Frontend

- Vue.js 3
- Vue Router + Vuex/Pinia
- Axios + Tailwind CSS
